📐 Methodology

Gravity = catGate(Catalysis) × survGate(RobustSurvival) × shape(0.45·Design + 0.25·Breadth + 0.30·Indispensability)

構造的影響力の指標。コミット数ではなく、コードがアーキテクチャにどれだけ織り込まれているかを測定する。

Debt Cleanup — 技術的負債の除去への貢献度。deprecated APIの削除、コンパイラ警告の修正、 不要コードの整理など。100は最高評価。

Catalysis / RobustSurvival — Gravity を通す2つのゲート。他者が生存コードの上に build-on したか（Catalysis）、他者の編集圧の下でコードが生き残ったか（RobustSurvival）。xuwei-k はいずれも 0 のため、shape に何が立っていても積は 0 になる。これが relational gravity の核心 — gravity は「設計の創始」でも「コミットの量」でもなく、他者との構造的な関係そのものを観測する。

なぜ Gravity 0 か — 多コミットでも、書いたコードが他者の圧の下で残らず（RobustSurvival 0）、誰もその上に積まなければ（Catalysis 0）、relational な構造依存はそこに無い。実際 Scala 2 では 709 人中 510 人が、Scala 3 では 895 人中 766 人が gravity 0 に並ぶ。gravity は活動量ではなく関係を測る指標であり、xuwei-k の働きは Impact と Debt Cleanup の信号で読むのが正しいのではないだろうか。
